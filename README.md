# 🌸 Frozen Garden

**A 3D Unity Game Jam platformer about bringing a frozen garden back to life.**

**English** · [Русский](#-русский)

## 🇬🇧 English

### About the game

*Frozen Garden* is a short 3D platformer built for a Game Jam around the theme **“Spring.”** The idea plays with two meanings of the word: **spring as a season** and **spring as a bouncing mechanism**.

Explore a frozen garden, awaken flowers, and watch the environment change as ice melts and greenery returns. Bounce on mushrooms to reach higher platforms, then find the main rose to awaken the garden.

### Gameplay features

- **Awaken flowers:** touching flowers triggers blooming animations and changes nearby parts of the environment.
- **Watch winter turn into spring:** ice pieces shrink and disappear, frozen platforms switch to their green versions, and snowy trees fade out.
- **Bounce on mushrooms:** mushrooms launch the player upward using physics, with squash-and-stretch animation and sound.
- **Explore in third person:** character movement, jumping, animations, and a smooth following camera.
- **Reach the final rose:** the rose blooms, surrounding objects grow, and the game concludes with **“Spring has awakened!”**

### Controls

| Action | Key |
| --- | --- |
| Move | WASD / Arrow keys |
| Jump | Space |

### Built with

- **Unity** — 3D game engine
- **C#** — gameplay scripting
- **Rigidbody physics** — movement, jumping, and mushroom bounce
- **Unity Animator** — movement and jump states
- **Coroutines** — blooming, melting, growth, and visual transitions
- **TextMeshPro** — objective and ending UI

## 🇷🇺 Русский

### Об игре

*Frozen Garden* — небольшой 3D платформер на Unity, созданный для Game Jam на тему **«Spring»**. Идея игры объединяет два значения английского слова: **весна** и **пружина**.

Игрок исследует замёрзший сад, пробуждает цветы и наблюдает, как меняется мир: лёд тает, снег исчезает, а растения оживают. Грибы работают как пружины и помогают добраться до высоких платформ. В конце путешествия нужно пробудить главную розу и вернуть сад к жизни.

### Особенности

- **Пробуждение цветов:** при касании цветы раскрываются и запускают изменения окружения.
- **Смена сезонов:** ледяные объекты постепенно исчезают, замёрзшие платформы заменяются зелёными, а заснеженные деревья плавно пропадают.
- **Грибы-пружины:** подбрасывают персонажа вверх с помощью физики, сопровождая прыжок анимацией сжатия и звуком.
- **Платформинг от третьего лица:** передвижение, прыжки, анимации персонажа и плавная камера.
- **Финальная роза:** её пробуждение запускает рост растений и завершает игру сообщением **«Spring has awakened!»**.
